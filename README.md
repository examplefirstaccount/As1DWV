# Highest Grossing Films Scraper and Viewer

This project scrapes data on the highest-grossing films from Wikipedia, stores it in a database and a JSON file, and displays the data in an interactive web table.

## Project Overview

The project consists of the following components:

1.  **as1.ipynb**: A Jupyter notebook containing the Python code for web scraping the Wikipedia page "List of highest-grossing films," parsing the extracted data, cleaning it, and saving it to an SQLite database and a JSON file.
2.  **grossing\_films.json**: A JSON file containing the scraped film data.
3.  **index.html**: An HTML file that structures the web page to display the film data in a table.
4.  **script.js**: A JavaScript file that fetches the data from `grossing_films.json`, populates the HTML table, and adds interactive features like searching and sorting.
5.  **styles.css**: A CSS file that styles the web page for a visually appealing presentation.
6.  **grossing\_films.db**: An SQLite database file containing the scraped film data (generated by the notebook).

## Setup and Usage

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/examplefirstaccount/As1DWV.git
    cd As1DWV
    ```

2.  **Install dependencies:**
    Make sure you have Python installed. You'll need the following Python libraries:
    ```bash
    pip install requests beautifulsoup4 lxml httpx sqlalchemy jupyter
    ```

3.  **Run the Jupyter Notebook:**
    Launch Jupyter Lab or Jupyter Notebook in the project directory and open `as1.ipynb`. Run all the cells in the notebook. This will perform the scraping, data cleaning, and create the `grossing_films.json` and `grossing_films.db` files.

4.  **View the interactive table:**
    Open the `index.html` file in your web browser. You should see the table populated with the film data. You can search the table by film title and sort the columns by clicking on the headers.

## Features

*   Scrapes data from four different tables on the Wikipedia "List of highest-grossing films" page.
*   Extracts key information: title, release year, director(s), box office revenue, and country of origin.
*   Uses asynchronous fetching (`httpx`) for faster scraping.
*   Cleans and formats the scraped data, removing references and standardizing values.
*   Stores the data in an SQLite database (`grossing_films.db`).
*   Exports the data to a JSON file (`grossing_films.json`).
*   Displays the data in a searchable and sortable HTML table using JavaScript.
*   Styled with CSS for a clean and responsive user interface.

## Technologies Used

*   **Python:** Web scraping, data processing, database interaction.
    *   `requests`, `beautifulsoup4`, `lxml`, `httpx`, `sqlalchemy`
*   **Jupyter Notebook:** Development and execution environment for the Python code.
*   **HTML:** Structuring the web page.
*   **CSS:** Styling the web page.
*   **JavaScript:** Fetching data, populating the table, adding search and sort functionality.
*   **SQLite:** Database for storing the scraped data.
